## Utilisation LaStarter

- **Hors catalogue v1** (trop gros pour la cible PME collaborative), mais à
  documenter comme extension majeure possible : un client LaStarter peut
  installer ERPNext dans son bench exactement comme une autre app — c'est la
  force du modèle. Vérifier le poids ops (workers, volume de données) avant
  de l'offrir en option cloud.
- La maturité ERPNext est aussi un garant pour le framework lui-même : 20 ans
  de production dessus.
